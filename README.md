# Single-Cell Profiling of Early Breast Cancer Dissemination and Immune Reprogramming

> Course:     Scientific Programming (MSB1015) \
> Date:       18.10.2026 

This project investigates single-cell RNA sequencing (scRNA-seq) data with the objective of enhancing our understanding of the role of the immune response in early breast cancer dissemination. The analysis follows a standard scRNA-seq workflow, which includes quality control, preprocessing, and cell-type clustering. The clustering process is executed at two distinct levels: initial broad clustering to identify major cell populations, followed by subsequent fine-grained clustering to characterize specific immune cell populations. The resulting clusters are then used for downstream gene regulatory network (GRN) analysis using the pySCENIC workflow [1], enabling the investigation of transcription factor activity and gene regulatory programs associated with immune cell populations.

## Dataset 

The data used in this project are publicly available in the Gene Expression Omnibus (GEO) database
under accession number [**GSE225600**](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE225600). 

## How to Run the Scripts

Each script is executed independently from the project root directory (MSB1015). Outputs are stored in a date-specific run directory under results/runs/, including log files, figures, and data files where applicable.

Run the scripts in the order listed below to follow the analysis pipeline. For example, to load the raw data, execute:

`python -m scripts.01_load_data`

## Scripts in Detail

### `01_load_data.py`

**Workflow steps:**
1. Data loading
2. Raw data quality control
3. Quality control threshold assessment
4. Confounder investigation

**Input**: original dataset and supplementary files in `data/raw/` \
**Output**: 
- AnnData object containing the loaded data
- quality control figures, including violin plots, scatter plots, and histograms
- distribution summaries
- PCA visualizations

### `02_preprocessing.py`

**Workflow steps:**
1. Quality Control Threshold Selection
2. Doublet Detection and Removal
3. Normalization and Log Transformation
4. Highly Variable Gene (HVG) Analysis
5. Highly Expressed Gene Analysis
6. Random Sampling
7. Batch Correction

**Input**: AnnData object generated by `01_load_data.py` \
**Output**: 
- preprocessed AnnData object
- diagnostic figures for quality control threshold selection, HVG analysis, highly expressed genes, and batch correction

### `03_clustering.py`

**Workflow steps:**
1. Marker Gene Curation
2. Broad Cell Clustering
3. Clustering Stability Assessment
4. Immune Cell Subset Selection
5. Fine-Grained Clustering
6. Clustering Stability Assessment
7. Cell Type Annotation
8. Cell Type Relative Abundance Analysis

**Input**: preprocessed AnnData object generated by `02_preprocessing.py` \
**Output**: 
- clustered AnnData objects (current and legacy versions)
- cell-type annotation tables
- clustering results
- diagnostic figures
- relative abundance analyses
